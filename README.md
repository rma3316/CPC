## 🎮 조작 방법 (Controls)

기본 조작키는 아래와 같으며, 로비 우측 하단의 **[⚙ 설정]** 메뉴에서 원하시는 키로 자유롭게 변경할 수 있습니다!

| 기본 단축키 | 동작 | 설명 |
|---|---|---|
| **`←`** / **`→`** | 좌우 이동 | 블록을 왼쪽이나 오른쪽으로 이동합니다. |
| **`↓`** | 소프트 드롭 | 블록을 빠르게 아래로 내립니다. |
| **`Space`** | 하드 드롭 | 블록을 바닥에 즉시 떨어뜨리고 고정시킵니다. |
| **`↑`** | 시계 방향 회전 | 블록을 오른쪽으로 90도 회전합니다. |
| **`Z`** | 반시계 방향 회전 | 블록을 왼쪽으로 90도 회전합니다. |
| **`C`** | 홀드 (Hold) | 현재 블록을 보관(저장)하거나 저장된 블록과 교체합니다. |
| **`R`** | 게임 리셋 | 싱글플레이(혼자 플레이) 중 판을 즉시 초기화하고 재시작합니다. |

## 🏆 게임 규칙 (Rules)

1. **블록 쌓기 및 줄 지우기**: 떨어지는 테트로미노 블록을 조작하여 빈칸 없이 가로줄을 채우면 해당 줄이 삭제되며 점수를 얻습니다.
2. **상대방 공격하기 (멀티플레이)**:
   - 한 번에 **여러 줄(2~4줄)**을 지우면 다른 플레이어에게 방해 블록(쓰레기 줄)을 보냅니다.
   - 연속으로 줄을 지우는 **콤보(Combo)**나 **T-Spin** 기술을 사용하면 더 강력한 공격이 가능합니다.
3. **생존 경쟁**: 블록이 화면 최상단까지 쌓여 더 이상 블록을 놓을 수 없게 되면 탈락(Game Over)합니다. 최후의 1인이 될 때까지 살아남으세요!

## 💻 로컬에서 게임 실행해보기 (For Local Play)

만약 이 게임을 직접 자신의 컴퓨터에서 실행해보고 싶다면 아래 단계를 따라주세요.

1. **필수 설치**: 컴퓨터에 [Node.js](https://nodejs.org/)가 설치되어 있어야 합니다.
2. **서버(Backend) 실행**:
   ```bash
   cd server
   npm install
   npm run dev
   ```
3. **클라이언트(Frontend) 실행** (새로운 터미널 창에서):
   ```bash
   cd client
   npm install
   npm run dev
   ```
4. 터미널에 표시된 주소(예: `http://localhost:5173`)로 브라우저를 통해 접속하면 게임을 즐길 수 있습니다. 브라우저 창을 여러 개 띄우면 혼자서도 다인 플레이를 테스트할 수 있습니다!
